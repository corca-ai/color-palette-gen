# Documentation map

This index separates current truth surfaces from research evidence and preserved
history. A document's status controls how it may be used:

- **Normative**: owns a current product, runtime, policy, or operating contract.
- **Explanatory**: explains normative behavior but does not override code or policy.
- **Research**: records a bounded diagnostic observation or counterfactual.
- **Historical**: preserves earlier intent and is not current authority.
