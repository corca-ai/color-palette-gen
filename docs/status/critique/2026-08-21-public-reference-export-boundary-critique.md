# Public reference export boundary critique

Date: 2026-08-21

## Decision under review

Keep the public export surface bounded to one project-owned reference token
schema while preserving the applied specimen as an explanatory surface.

## Execution

- Target: public schema and ownership boundary.
- Angles: first-reader/title-cite coherence and operational dependency cascade.
- Counterweight: challenged both an underspecified export and an unnecessarily
  broad compatibility promise.
- Packet consumed: n/a; the repository has no critique adapter sections.
- Reviewer boundary fingerprints: all three reviewer windows returned `clean`
  with no drift.
- Fresh-eye satisfaction: `parent-delegated`.

## Counterweight triage

### Act before ship

- Give the reference token payload one stable schema identity.
- Preserve complete Light/Dark role coverage and policy provenance.
- Keep the applied specimen project-owned and understandable without knowledge
  of another application.
- Rebuild the public artifact and verify the exported schema through its public
  serializer and browser example.

### Bundle anyway

- Record the public schema boundary in ADR-0009.
- Keep positive reference-export coverage.
- State explicitly that the export does not certify application-level use.

### Over-worry

- Do not remove `reference-export.js` or the applied specimen; both have
  independent project-owned duties.
- Do not redesign palette eligibility in this slice.

### Valid but defer

- Application-specific aliases, derived component roles, and browser behavior
  require validation in the application that uses the exported tokens.

## First-reader probe

The intended reading is: generated palette → Color Lab applied example →
project-owned reference export. No external application knowledge is required.

## Boundary ownership

- Palette generator: generated roles, values, and policy provenance.
- Reference export: stable names for every generated Light/Dark role.
- Applying application: aliases, derived roles, components, and browser use.
- Verdict: `moved-to-owner`.
